Hospital Readmission Real-World Evidence Analysis

Author

Charles Waweru

Published

today

1 Executive Summary

This project demonstrates a reproducible real-world evidence (RWE) workflow using a synthetic hospital admissions dataset. The analysis examines 30-day readmission, patient characteristics, diagnosis groups, and length of stay.

The dataset is synthetic and does not represent real NHS patients. Results are intended to demonstrate analytical methods rather than describe actual hospital performance.

2 Research Questions

  1. What is the 30-day readmission rate in the eligible cohort?
  2. Which patient and admission characteristics are associated with readmission?
  3. Does adding diagnosis group improve the adjusted readmission model?
  4. Which characteristics are associated with length of stay?

3 Data and Study Population

The analysis uses a synthetic hospital admissions dataset. The eligible index cohort is restricted to qualifying 2025 discharges without a recorded discharge in the preceding 30 days.

Readmission is defined as a subsequent emergency or urgent non-emergency admission within 30 days of index discharge.

4 Statistical Methods

Descriptive statistics and adjusted logistic regression are used to examine 30-day readmission. An exploratory model comparison assesses whether diagnosis group adds explanatory value.

Length of stay is examined separately using a Gamma regression model with a log link and a patient-clustered generalized estimating equation.

5.3 Does Diagnosis Group Improve the Readmission Model?

We compared two adjusted logistic regression models using the same 1,368 complete-case admissions from 922 patients.

  • Model A: admission type, age, sex, and comorbidity count.
  • Model B: Model A’s predictors plus diagnosis group.

The likelihood-ratio test assessed whether adding diagnosis group improved model fit. AIC and BIC were used to compare model fit while penalising model complexity. Apparent AUC measures discrimination on the same data used to fit the models.

The likelihood-ratio test did not provide strong evidence that adding diagnosis group improved model fit (chi-squared = 9.83, 8 degrees of freedom, p = 0.277). AIC and BIC favoured the simpler model.

Although Model B had a higher apparent AUC, the preliminary five-fold cross-validated mean AUCs were very similar (0.605 for Model A and 0.609 for Model B). The small difference does not establish a meaningful improvement in performance on new patients.

Model A was therefore retained as the provisional primary model, while Model B was treated as an exploratory analysis.

5.4 Length-of-Stay Analysis

Length of stay (LOS) was analysed using a Gamma regression model with a log link and patient-clustered generalized estimating equations (GEE). This approach accounts for the positive, right-skewed nature of LOS and allows for correlation between repeated admissions from the same patient.

Results are presented as expected length-of-stay ratios. A ratio above 1 indicates a higher expected LOS, while a ratio below 1 indicates a lower expected LOS, conditional on the model covariates.

In this model, the estimated expected LOS was approximately 9% lower for urgent non-emergency admissions than for emergency admissions. However, the confidence interval included 1 and the p-value was approximately 0.056, so the evidence did not meet the conventional 5% significance threshold.

The other reported covariates also did not show statistically significant associations with LOS at the 5% level in this model. These estimates are exploratory and are based on synthetic data.

6 Limitations

The dataset is synthetic. The adjusted analyses used complete cases, which may limit the representativeness of the analytical sample. Model validation was preliminary, and observed associations do not establish causation. Model performance on synthetic data does not establish predictive performance in real clinical settings.

7 Reproducibility

Analysis scripts and generated outputs are maintained separately from this report so the workflow can be rerun and audited.

8 Conclusion

This project demonstrates an end-to-end real-world evidence (RWE) analytical workflow using a synthetic hospital admissions dataset. The analysis covered cohort definition, descriptive statistics, adjusted logistic regression, model comparison, and patient-clustered analysis of length of stay.

The adjusted analysis identified associations between 30-day readmission and both age and comorbidity count. However, these findings are based on synthetic data and should not be interpreted as evidence of clinical effects or used to guide patient care.

Adding diagnosis group produced only a small difference in cross-validated AUC compared with the simpler model. The likelihood-ratio test did not provide strong evidence of improved model fit, supporting retention of the simpler adjusted logistic regression as the provisional primary model.

Overall, this project demonstrates the importance of transparent reporting, reproducible analytical workflows, appropriate handling of repeated patient admissions, and balancing model complexity against performance when developing RWE analyses.
